   - Реалізовано інтерфейс адміністрування товарів (`/admin/products`): форма додавання нового товару та видалення наявних.
4. **Рівень 2 (Додаткова сутність предметної області - Клієнти / Customers):**

6. **Архітектура коду (Flask Blueprints):**

## 3. Схема реалізованої частини бази даних

```sql
-- 1. Відгуки
CREATE TABLE feedbacks (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    email TEXT NOT NULL,
    message TEXT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 2. Товари
CREATE TABLE products (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    category TEXT NOT NULL,
    price REAL NOT NULL,
    description TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 3. Клієнти (Рівень 2)
CREATE TABLE customers (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    email TEXT NOT NULL,
    phone TEXT,
    address TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

## 4. Відповіді на контрольні запитання
1. **Що таке база даних і СКБД? Чим вони відрізняються?**
   - *База даних (БД)* — це організована структура даних, що зберігається на носії інформації.
   - *СКБД (Система керування базами даних)* — це комплекс програмного забезпечення (наприклад, SQLite, PostgreSQL, MySQL), який надає інструменти для створення, читання, оновлення, пошуку та захисту інформації в БД.
2. **Що таке реляційна модель даних?**
   - Модель, де дані представлені у вигляді двовимірних таблиць (відношень). Рядки (кортежі) містять конкретні записи, а стовпці (атрибути) — певні властивості сутності.
3. **Що таке первинний і зовнішній ключі?**
   - *Первинний ключ (PRIMARY KEY)* унікально ідентифікує кожен запис у таблиці (наприклад, `id` у таблиці `products`).
   - *Зовнішній ключ (FOREIGN KEY)* пов'язує запис однієї таблиці з первинним ключем іншої (наприклад, `customer_id` у таблиці `orders` посилається на `customers(id)`).
4. **Як реалізувати зв'язок «багато-до-багатьох» між замовленнями й товарами?**
   - Створюється проміжна зв'язуюча таблиця (junction table) `order_items`, що містить зовнішні ключі `order_id` (посилання на `orders.id`) та `product_id` (посилання на `products.id`), а також додаткові атрибути (кількість `quantity`, ціна на момент замовлення `price`).
5. **Що означає абревіатура CRUD і яким SQL-командам відповідає?**
   - **C**reate -> `INSERT`
   - **R**ead -> `SELECT`
   - **U**pdate -> `UPDATE`
   - **D**elete -> `DELETE`
6. **Переваги та обмеження SQLite:**
   - *Переваги:* безсерверна, нульова конфігурація, зберігається в одному файлі, швидка для читання та прототипування.
   - *Обмеження:* блокування всього файлу БД при записі (не підходить для високонавантажених систем із багатьма одночасними записами).
7. **Що таке SQL-ін'єкція і як захищають параметризовані запити?**
   - Атака, коли зловмисник впроваджує шкідливий SQL-код через вхідні поля. Параметризовані запити (із символом `?`) розділяють SQL-команду та дані: дані передаються окремо і не інтерпретуються СКБД як команди.
8. **Навіщо відкривати й закривати з'єднання з БД для кожного запиту та викликати commit()?**
   - Відкриття у контексті запиту запобігає витоку ресурсів пам'яті та блокуванню файлу бази даних іншими процесами/потоками. `commit()` фіксує виконані зміни на диск, без нього транзакція відкочується.
